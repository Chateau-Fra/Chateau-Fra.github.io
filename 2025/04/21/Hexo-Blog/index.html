从零开始搭建博客

本文为hexo+GitHub博客搭建

准备工作：git、nodejs、GitHub账号。

Git

Node.js — 在任何地方运行 JavaScript

github.com

什么是Hexo

正如hexo的首页所显示的，它是一款非常快速，简介，高效的博客框架平台，我们可以利用hexo快速生成博客网站的模板，然后部署为我们自己的博客网站。

Hexo

GitHub注册

因为我的账号是之前就注册好的，但是为了防止没用过GitHub的人遇到困难，也简单说一下。

因为GitHub的服务器在国外，所以国内访问速度就很呃……😴。有些地方直接就访问不了，所以要用一些魔法找身边的大佬问一下，也可以用国内的网站平替一下，gitee等等。因为我没用过就不多说了。

注册只需要一个邮箱、一个用户名（随你喜欢）、一个密码就搞定了，按照步骤一步一步来。难点主要就是正常访问，解决这个问题之后注册应该是有手就行。
